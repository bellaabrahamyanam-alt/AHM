# Proposals to change an interface

A proposal is a NEW file `proposals/NNN-<name>.md` (any domain). Say: current text, new text, who is affected, migration steps, tests to
add. Nothing is implemented before the owner writes `Status: approved` in the file. After approval the integrator updates
`INTERFACES.md` (and its version) and each affected domain adapts in its own change. Existing proposals are not edited by agents.
