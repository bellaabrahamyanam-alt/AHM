# Requests between domains

A request is a NEW file `requests/<from>-to-<to>-NNN-<name>.md` written by the asking domain, never an edit of another domain's code
(DOMAINS.md). Say: what you need, why, and the exact interface call you expect. The owner forwards it; the owning domain implements it in
its own domain and answers in its own `changes/<domain>.md`. Existing requests are not edited.
